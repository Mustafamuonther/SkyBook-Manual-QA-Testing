# SkyBook – Bug Reports

This folder documents defects identified during manual testing of the SkyBook Flight Booking System.

## Bug Summary

- **Total Reported Bugs:** 28
- **Testing Type:** Manual Testing
- **Defect Tracking Tool:** Jira
- **Project Key:** SKYB

## Key Defects Identified

1. Same origin and destination accepted.
2. Return date earlier than departure date accepted.
3. Past travel dates accepted.
4. Flight booking allowed with zero adults.
5. Number of infants exceeds the number of adults.
6. Nonstop flight filter not working correctly.
7. Incorrect flight price sorting.
8. Invalid passenger email accepted.
9. Invalid phone number accepted.
10. Future date of birth accepted.
11. Passport expiry date earlier than travel date accepted.
12. Duplicate seat selection allowed.

## Defect Management Process

Defects were identified through manual test execution and documented in Jira.

Each defect is intended to be traceable to its related test case and user story.

## Jira Project

[SkyBook Jira Project](https://mostafaqaworkspace.atlassian.net/jira/software/projects/SKYB/boards/35/backlog?epics=visible)

Detailed bug reports, including reproduction steps, expected results, actual results, and severity, will be added from the Jira records.
