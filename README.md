# ✈️ SkyBook – Manual QA Testing Project

**End-to-End Manual Testing | Jira | Zephyr | Bug Reporting | Requirements Traceability**

## 📌 Project Overview

SkyBook is a flight booking application used for a practical Software Quality Assurance project.

The objective was to validate core booking functionality, identify defects, document test cases, execute manual tests, and maintain traceability between requirements, test cases, and reported bugs.

## 🐞 Key Defects Identified

Some important defects discovered during testing included:

- Same origin and destination accepted during flight search.
- Return date earlier than departure date accepted.
- Past travel dates accepted.
- Booking allowed with zero adult passengers.
- Infant count exceeding adult count accepted.
- Nonstop flight filter not working correctly.
- Incorrect price sorting.
- Invalid passenger email and phone number accepted.
- Future date of birth accepted.
- Invalid passport expiry date accepted.
- Duplicate seat selection allowed.
