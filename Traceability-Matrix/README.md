# SkyBook – Requirements Traceability Matrix

This folder contains the Requirements Traceability Matrix (RTM) for the SkyBook Flight Booking System.

## Project Overview

- **Epics:** 7
- **User Stories:** 20
- **Manual Test Cases:** 48
- **Reported Bugs:** 28
- **Test Management Tool:** Jira

## Purpose

The traceability matrix maps project requirements to test cases, execution results, and reported defects.

It helps demonstrate requirement coverage and provides traceability between user stories, test cases, and defects.

## Traceability Structure

Epic → User Story → Test Case → Execution Result → Bug Report

## Source

The traceability information was maintained as part of the SkyBook manual QA testing project.
